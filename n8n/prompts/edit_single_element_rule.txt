SINGLE-ELEMENT EDIT DISCIPLINE

When multiple furniture or layout changes are implied, apply only the PRIMARY EDIT below — one object or one cohesive change at a time.

Hold all other furnishings, rugs, lamps, wall art, and decor fixed in their current positions, scale, and identity unless the edit explicitly requires moving them to complete that one change.

Do not use this edit to refresh the whole room, swap unrelated pieces, or “improve” layout beyond the stated instruction.
